# v0.6.0-beta.1 Release Checklist

## Candidate identity

- Release: `v0.6.0-beta.1`
- Package version: `0.6.0b1`
- Phase master and release issue: #150
- Release branch: `release/150-v0.6.0-beta.1`
- Release target: verified `main` commit after the release PR
- Release type: GitHub pre-release
- Production promotion: separate explicit manual decision

The release branch predates the Phase 7 NFL commits already present on
`develop`. It therefore targets `main` directly for this release. After the
release is published, the verified `main` release state must be integrated
back into `develop`; the operator performs both merges.

## Scope boundary

The release retains the six Phase 5 authorities and adds exactly two bounded
OpenLigaDB authorities:

1. UEFA Nations League A 2026/27 group phase: 48 fixtures and 16 participants;
2. UEFA Champions League 2026/27 league phase: 144 fixtures and 36 participants.

Europa League, Conference League, EURO 2028 qualification, later Champions
League stages, later Nations League stages, and every Phase 7-9 feature are
outside this release. Both new authorities are permanently removal-disabled.
