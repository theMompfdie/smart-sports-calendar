## Scope boundary

The release contains six configured 2026/27 authorities:

1. Premier League through football-data.org;
2. Bundesliga through football-data.org;
3. EFL Championship `REGULAR_SEASON` through football-data.org;
4. DFB-Pokal through permanent-partial OpenLigaDB;
5. 2\. Bundesliga through removal-disabled OpenLigaDB;
6. ÖFB-Cup through the private permanent-partial official iCalendar feed.

Austrian Bundesliga, FA Cup, EFL Cup, and UEFA competitions are explicitly
deferred. This release does not add automatic failover, provider aggregation,
live scores, standings, statistics, or automatic production promotion.
